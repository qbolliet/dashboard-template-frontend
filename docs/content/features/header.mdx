## Explorer les paramètres

`Header` choisit seul entre barre horizontale et rail latéral repliable selon
la profondeur de l'arbre de navigation — la surface de contrôle est donc
volontairement mince. Ce playground démontre `onNavigationItemClick`, le seul
point d'extension qui n'est pas déjà exercé par le `<Header>` du site de
documentation lui-même.
